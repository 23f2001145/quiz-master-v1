# Quiz Master

A web-based quiz management platform built using Flask. The application allows users to attempt timed quizzes while providing administrators with tools to create and manage quizzes and questions.

## Features

- User authentication
- Timed quizzes
- Automatic score calculation
- Quiz and question management
- Admin dashboard

## Tech Stack

- Python
- Flask
- SQLite
- HTML
- CSS
- Bootstrap
- Jinja2
- JavaScript

## Installation

```bash
pip install -r requirements.txt
python app.py
